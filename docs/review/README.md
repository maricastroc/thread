# Visual review

Captures of the Lúcia demo at 1440 × 900 (mobile at 390 × 844), each in the light and the dark theme. Every `-light` / `-dark` pair was taken in the same state; during playback the audio was slowed to a near stop so both themes show the same moment.

- `review-sheet.jpg`: the ten key screens on one page.
- `light-and-dark.jpg`: the same states side by side in both themes.

Playback uses "Como conheceu o avô em festa" (c. 1966): at 0:19 "José" is being said and his thread reaches 1978, 1995 and 2010; at 0:50 "Graça" reaches back to 1956 and 1958 while José and Iquixadá stay as traces and Antônio is not said yet.

The empty archive, the setup and the zero-story recording come from separate data folders, so the demo archive was not changed: an empty archive for Lúcia, a fresh install, and a copy of the demo with a microphone test added.
